# STAT 139 Teaching

## Overview

This is the repository for my teaching material for Harvard's [Statistics 139](https://qrd.college.harvard.edu/directory/stat-139/), a course on linear models. Each week will have a corresponding folder that contains the .tex file, rendered .pdf, and any necessary figures. Importantly, a "student" (no-solution) version can be attained by toggling the `\solutionsfalse` line in the .tex file.
